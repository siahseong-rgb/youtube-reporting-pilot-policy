Private, read-only OAuth pilot

YouTube Reporting Pilot

This application supports a private UAC YouTube reporting pilot. It is used only by the actual owner of an authorized YouTube channel to generate internal performance reporting.

What it does

After the channel owner gives explicit Google OAuth consent, the pilot reads only the YouTube Analytics and YouTube Data information required to prepare reporting. It requests the minimum read-only scopes: yt-analytics.readonly and youtube.readonly. It does not request permission to upload, edit, delete, or publish YouTube content.

Who may use it

This is not a public consumer service. A personal OAuth client does not grant access to a UAC channel by itself. Access is available only when the actual channel owner authorizes the application and the use is permitted by the organization that owns the channel and its data.

Data handling

When the pilot is activated, authorized read-only reporting data is used solely to produce the approved internal reports. Credentials, refresh tokens, source code, operational logs, and UAC reporting data are not published on this website or its public source repository.
